# Pangasinan Heritage Digital Showcase

Student Name: Alma L. Fernandez

Selected Framework: Next.js 14 with React

Live Website: https://Maurik22.github.io/mau/

This is a static website about selected heritage places in Pangasinan. It has a Home page, Places page, About page, and detail pages for six places.

## Run locally

1. Run `npm install`.
2. Run `npm run dev`.
3. Open `http://localhost:3000`.

## Build

Run `npm run build`. Next.js creates the static files in the `out` folder.

## Activity 2 checks

The website uses mobile-first CSS, reusable components from Activity 1, static detail pages, image alt text, and a labeled search form. The GitHub Actions file builds and publishes the `out` folder to GitHub Pages.

## Lighthouse

After the site is live, run Lighthouse for Performance, Accessibility, Best Practices, and SEO. Write the scores in `documentation/Lighthouse-Audit-Results.md` and submit a screenshot or PDF.
