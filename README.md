# Pangasinan Heritage Digital Showcase

Student Name: Alma L. Fernandez

Selected Framework: Next.js 14 with React

Live Website: https://maurik22.github.io/pangasinanheritageact/

This project is a static website about selected heritage places in Pangasinan. It includes Home, Places, About, and detail pages.

The project uses reusable Atomic Design components, mobile-first CSS, image alt text, static detail pages, and GitHub Actions for GitHub Pages deployment.

## Run locally

1. Open the project folder:
   `source-code/pangasinan-heritage`
2. Run `npm install`.
3. Run `npm run dev`.
4. Open `http://localhost:3000`.

## Build

Run `npm run build`. Next.js creates the static files in the `out` folder.
